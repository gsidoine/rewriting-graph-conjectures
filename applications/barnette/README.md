# Barnette: Exact Defect and Three-Face Normalization

A state is a nontrivial binary colouring of the dual Eulerian triangulation. The exact potential

```text
Phi = z + 2(t - 1)
```

measures the omitted primal vertices and cycle components of the corresponding even subgraph. Rewrites flip connected face patches without increasing `Phi`.

The verified data show that one- and two-face normalization can become trapped, while connected three-face flips resolve the audited examples. The historical 48-vertex mask file is retained only as an explicitly inconsistent certificate.
