# Complexity Result

Near-Unicyclic Matching Decycling is NP-complete even with exactly three leaves, all other degrees three, no leafless bridge side, and a supplied near-unicyclic matching.  The reduction starts from Hamiltonian `s-t` path in the Hamiltonian fairly cubic instances constructed by Protti and Souza; their construction supplies the Hamiltonian cycle used to define the promised matching.
