# Candidate Inventory

The selection emphasized problems compatible with certificate states, exact defects, and local rewrites.

| Problem | OPG rating | Rewriting state | Assessment |
|---|---:|---|---|
| 3-Decomposition Conjecture | 3 stars | spanning tree and cotree defect | Best fit; existing programme yields safe moves, finite plateau verification, obstruction and hardness theorem. |
| 3-Edge-Coloring Conjecture | 3 stars | proper edge-colouring / nowhere-zero 4-flow plus edge suppression | Strong fit for removable-edge search; finite verification added. Recent work gives a nonempty removable set of size at most `|E|/6`, but the one-edge conjecture remains open in the nonbipartite case. |
| Cycle double covers containing a prescribed 2-regular subgraph | 3 stars | cycle-cover incidence vector with frozen coordinates | Natural rewrite target, but fixed-subgraph rigidity resembles the obstruction found in 3-Decomposition; no new theorem obtained. |
| Strong 5-cycle double cover conjecture | 3 stars | five-cycle multicover defect | High significance but state space and local moves were not sufficiently mature in this pass. |
| Matching cut and girth | 2 stars | vertex bipartition with crossing-edge conflict defect | Promising probabilistic/local-lemma direction; no bound for general average degree `d` was proved. |
| Minimal graphs with a prescribed number of spanning trees | 2 stars | series-parallel composition and multiplicative/additive tree counts | Attractive arithmetic construction problem, but not as close to the current graph-rewrite machinery. |

The Open Problem Garden pages are treated only as statements/rating snapshots.  Current mathematical status was checked against recent primary literature before selecting targets.
