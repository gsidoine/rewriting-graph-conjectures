## Manuscript programme

The following manuscripts are maintained in a separate private author bundle while they are prepared for submission:

1. *Quadratic Descent for Six Perfect Matchings in Cubic Graphs*;
2. *Basis-Exchange Normalization and Fixed-Cycle Obstructions for the 3-Decomposition Conjecture*;
3. *Three-Face Normalization for Barnette Graphs*.

The public repository deliberately contains the software, exact data, certificates, and mathematical-status ledger rather than a moving copy of every manuscript. This keeps the research programme clear and avoids having several uncontrolled manuscript versions in circulation.

When a manuscript is ready, the recommended workflow is:

1. freeze a versioned GitHub release of the exact code and data used in the paper;
2. archive that release with Zenodo or an equivalent service to obtain a DOI;
3. post the manuscript as a clearly labelled preprint when appropriate;
4. add the preprint/journal citation and DOI here;
5. update the preprint after publication with a link to the version of record.
