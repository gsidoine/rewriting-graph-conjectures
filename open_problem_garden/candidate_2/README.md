# Candidate 2 — Matching Cut and Girth

Proposed state: a nontrivial vertex bipartition.  Proposed defect: the number (or excess degree) of vertices incident with more than one crossing edge.  Zero defect means the cut edges form a matching.

The local-flip programme did not produce a universal descent theorem.  High girth suppresses short local obstructions but does not by itself guarantee that defect descent preserves two nonempty sides.  No mathematical result is claimed from this branch.
