# Selection Criteria

A problem received priority when it had:

1. a finite certificate state with efficiently checkable validity;
2. a natural integer defect vanishing exactly at the target;
3. local moves preserving the ambient graph class;
4. a first unresolved layer small enough for exact enumeration;
5. a plausible route from computational obstructions to a universal theorem.

3-Decomposition scored highest on all five.  The removable-edge conjecture was chosen as a secondary target because edge deletion/suppression produces a sharply testable local operation and because recent flow results identify the exact gap between a small removable set and a single removable edge.
