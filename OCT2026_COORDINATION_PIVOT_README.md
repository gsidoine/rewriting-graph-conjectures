# October 2026 — Certificate coordination and obstruction hypergraphs (v7)

This **additive research branch** develops the general coordination direction previously identified but not pursued. It contains a new theorem-led draft at `certificate_coordination/paper/main.pdf`, exact construction/verification scripts, and `certificate_coordination/RESEARCH_STATUS.md`.

**Main results (internal proof draft, externally unrefereed):** for any fixed edge-connectivity c, shortest strict one-coordinate normalization and minimum direct repair width are NP-complete in generalized d-fold perfect-matching systems on connected d-regular bipartite graphs. A separate family on K_(d,d) gives constant defect 4 one-coordinate traps at unbounded maximal edge-connectivity. Both constructions have explicit certificates, and universal proofs are contained in the paper.

Do not confuse the generalized one-fold setting with the original six-perfect-matching two-fold Berge–Fulkerson state model. No classical open conjecture is claimed solved. Previous release status files and all prior research branches are preserved. The private live GitHub `main` branch has not been modified.
